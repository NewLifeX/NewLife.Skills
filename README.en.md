NewLife.Skills centrally manages reusable Copilot instructions, skills and agents for NewLife repositories; one script installs them into VS Code.

## Installation

```bash
# Clone the repository and build
dotnet build
```

## Quick start

```powershell
pwsh -File install-copilot-assets.ps1
```

## Key features

- Comprehensive Chinese docs with examples and migration guides
- Companion CLI, debugging and visualization tools
- Pluggable, extensible architecture for custom development

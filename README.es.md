NewLife.Skills gestiona centralmente instrucciones, habilidades y agentes de Copilot reutilizables para los repositorios NewLife; un script los instala en VS Code.

## Instalación

```bash
# Clone the repository and build
dotnet build
```

## Inicio rápido

```powershell
pwsh -File install-copilot-assets.ps1
```

## Características

- Documentación completa en chino con ejemplos y guías de migración
- Herramientas CLI, de depuración y visualización
- Arquitectura extensible y conectable para desarrollo propio

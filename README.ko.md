NewLife.Skills는 NewLife 저장소용 Copilot 지침·스킬·에이전트를 중앙 관리하며, 스크립트 하나로 VS Code에 설치합니다.

## 설치

```bash
# Clone the repository and build
dotnet build
```

## 빠른 시작

```powershell
pwsh -File install-copilot-assets.ps1
```

## 주요 기능

- 예제와 마이그레이션 가이드를 포함한 풍부한 중국어 문서
- CLI, 디버깅, 시각화 도구 제공
- 플러그인 방식의 확장 가능한 아키텍처

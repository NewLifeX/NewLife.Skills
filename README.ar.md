> قد تتأخر هذه الترجمة عن النسخة الصينية.

يدير NewLife.Skills مركزيًا تعليمات ومهارات ووكلاء Copilot القابلة لإعادة الاستخدام لمستودعات NewLife، ويثبّتها في VS Code بسكربت واحد.

## التثبيت

```bash
# Clone the repository and build
dotnet build
```

## البدء السريع

```powershell
pwsh -File install-copilot-assets.ps1
```

## الميزات الرئيسية

- توثيق صيني شامل مع أمثلة وأدلة ترحيل
- أدوات سطر أوامر وتصحيح ومرئيات مرافقة
- بنية قابلة للتوسع والإضافات لتطوير مخصص

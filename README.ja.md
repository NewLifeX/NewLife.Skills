NewLife.Skills は NewLife リポジトリ向けの Copilot 指示・スキル・エージェントを一元管理し、1 つのスクリプトで VS Code に導入できます。

## インストール

```bash
# Clone the repository and build
dotnet build
```

## クイックスタート

```powershell
pwsh -File install-copilot-assets.ps1
```

## 主な機能

- 中国語ドキュメントが充実し、サンプルと移行ガイドも用意
- CLI・デバッグ・可視化ツールを同梱
- プラグイン可能な拡張アーキテクチャで二次開発が容易

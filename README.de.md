NewLife.Skills verwaltet wiederverwendbare Copilot-Instruktionen, Skills und Agents für NewLife-Repositories zentral; ein Skript installiert sie in VS Code.

## Installation

```bash
# Clone the repository and build
dotnet build
```

## Schnellstart

```powershell
pwsh -File install-copilot-assets.ps1
```

## Funktionen

- Umfassende chinesische Dokumentation mit Beispielen und Migrationsleitfäden
- Begleitende CLI-, Debug- und Visualisierungswerkzeuge
- Plug-in-fähige, erweiterbare Architektur für eigene Entwicklung

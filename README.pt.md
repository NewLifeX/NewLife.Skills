NewLife.Skills gerencia centralmente instruções, habilidades e agentes Copilot reutilizáveis para os repositórios NewLife; um script os instala no VS Code.

## Instalação

```bash
# Clone the repository and build
dotnet build
```

## Início rápido

```powershell
pwsh -File install-copilot-assets.ps1
```

## Recursos

- Documentação completa em chinês com exemplos e guias de migração
- Ferramentas CLI, de depuração e visualização
- Arquitetura extensível e conectável para desenvolvimento próprio

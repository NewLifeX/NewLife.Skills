NewLife.Skills 集中管理 NewLife 系列可重複使用的 Copilot 指令、技能與智慧代理，一條指令碼安裝到 VS Code，無需在每個專案重複放置 .github。

## 安裝

```bash
# Clone the repository and build
dotnet build
```

## 快速開始

```powershell
pwsh -File install-copilot-assets.ps1
```

## 核心特性

- 中文文件完善，範例與移轉指引豐富
- 配套命令列、偵錯與視覺化工具
- 外掛化與可擴充架構，便於二次開發

NewLife.Skills centralise les instructions, compétences et agents Copilot réutilisables pour les dépôts NewLife ; un script les installe dans VS Code.

## Installation

```bash
# Clone the repository and build
dotnet build
```

## Démarrage rapide

```powershell
pwsh -File install-copilot-assets.ps1
```

## Fonctionnalités

- Documentation chinoise complète avec exemples et guides de migration
- Outils CLI, de débogage et de visualisation
- Architecture extensible et modulaire pour vos développements

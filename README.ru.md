NewLife.Skills централизованно управляет переиспользуемыми инструкциями, навыками и агентами Copilot для репозиториев NewLife; один скрипт устанавливает их в VS Code.

## Установка

```bash
# Clone the repository and build
dotnet build
```

## Быстрый старт

```powershell
pwsh -File install-copilot-assets.ps1
```

## Возможности

- Подробная документация на китайском с примерами и руководствами по миграции
- CLI, отладка и инструменты визуализации
- Расширяемая модульная архитектура для собственной разработки
